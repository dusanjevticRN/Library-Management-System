# Library-Management-System

Developed by me alone a long time ago, this project is built with pure code—no design patterns except for a singleton were used—and was created for fun with the idea that it could be used in in real-life library scenarios.

The application includes several stages: 
The Login and Registration stage for managing user access.
The BookStage, where workers can view, add, delete, and search for books available in the library.
The Settings stage, allowing customization of the app’s theme.
The FAQs stage, where frequently asked questions can be added to a list and printed for display in the library; and the Notice stage, similar to the FAQs stage but for general notices like library closures.
The core functionality happens in the Transaction stage, where workers can borrow or sell books, view borrowing records, and print bills.

Whole project has somewhere between 6000 and 8000 lines of code.
